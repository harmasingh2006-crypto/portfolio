# Harman Singh — Portfolio

A single-page portfolio built from scratch: biotech + computational biology + web/data skills, projects, certifications, and education.

- `index.html` — the entire site (HTML, CSS, and a touch of animation, all in one file). No build step, no dependencies to install.
- Fonts load from Google Fonts (IBM Plex Sans); everything else is self-contained.

## Editing it
Open `index.html` in any text editor. Content is in plain HTML further down the file; styles are in the `<style>` block at the top. Search for a project name, skill, or date to find the section you want to change.

## Deploying for free on GitHub Pages
See the step-by-step in the chat response, or:
1. Create a new public GitHub repo (e.g. `portfolio`).
2. Upload `index.html` to it.
3. In the repo, go to **Settings → Pages**, set the source branch to `main` and folder to `/root`, then save.
4. Your site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
